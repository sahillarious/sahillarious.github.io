B.O.L.T — Quadruped Vision & Voice Control

Real-time tracking and voice control on a Unitree Go2

GitHub → Watch Demo →

B.O.L.T (Behavioral Object Locomotion & Tracking) is a real-time vision-guided tracking and voice-control system built on a Unitree Go2 quadruped robot, developed as an EAS 563 AI Capstone project at the University at Buffalo, advised by Prof. David Doermann.

Perception & Control

A custom-trained YOLOv8 detector identifies and tracks a target object (color-coded balls) in real time, fused with Intel RealSense depth data for monocular distance estimation. A finite-state machine converts this visual feedback directly into velocity commands for the robot, enabling smooth closed-loop following without relying on SLAM. Occlusion-aware re-identification with Kalman filtering keeps the track stable through brief occlusions and target switches.

Voice Control

The system was extended with a hands-free voice interface: a Whisper speech-to-text pipeline feeds a lightweight regex-based command parser, which dispatches recognized commands over SSH to the robot's on-device execution loop. This supports 20+ distinct spoken behaviors, letting an operator direct the robot's movement and tracking targets verbally instead of through a keyboard or controller.

Performance

  • Average end-to-end latency: ~48ms (worst case ~61ms)
  • Detection accuracy: mAP@0.5 ≈ 0.995
  • Tracking success rate: >90% in indoor environments, robust across varied lighting

Stack

Python, YOLOv8 (Ultralytics), OpenCV, ROS/ROS2, Intel RealSense, Whisper STT, Jetson Nano
