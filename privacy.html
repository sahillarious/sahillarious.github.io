Privacy Policy — jobmail

Last updated: September 18, 2026

What jobmail is

jobmail is a personal tool used only by its developer, Sahil Sawant. It reads the developer's own job-application emails through the Gmail API and runs locally on the developer's computer.

Data accessed

Only the developer's own Gmail messages, through the read-only scope https://www.googleapis.com/auth/gmail.readonly. jobmail cannot send, modify or delete email.

How it is used

Emails are read only to extract company names, job titles and locations for the developer's own job-search tracking.

Storage

Extracted data and OAuth tokens are stored locally on the developer's computer only, not on any server run by the developer.

Sharing

No data is sold, used for advertising, or transferred to other people. One exception: limited excerpts of application emails may be sent to an AI model provider (Anthropic, via its API) solely to extract company and role. This is done under that provider's API terms, and the excerpts are not used for advertising or sold.

Google API Services User Data Policy

jobmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The developer can revoke jobmail's access at any time at myaccount.google.com/permissions and delete the local data.
