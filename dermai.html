DermAI

Dermatological image classification with LLM-grounded feedback

PyTorch ResNet50 EfficientNet-B0 SMOTE GPT-4 Gradio
GitHub →

Overview

DermAI is an ensemble diagnostic system for skin disease detection built on the HAM10000 dataset. Skin diseases affect millions globally, yet access to dermatologists remains limited — DermAI addresses this with high-accuracy lesion classification paired with an LLM layer that interprets results and generates clinically grounded, context-aware feedback through Gradio.

Approach

Data Processing & Augmentation

The HAM10000 dataset contains 10,015 dermatological images across 7 lesion types, with severe class imbalance (e.g. 6,705 Melanocytic Nevi vs. just 115 Dermatofibroma). SMOTE (Synthetic Minority Over-sampling Technique) and custom class weighting address this imbalance, while random rotations, horizontal/vertical flips, and normalization improve model robustness.

Ensemble Transfer Learning

Rather than relying on a single model, DermAI combines four state-of-the-art architectures: ResNet50 for deep residual features, DenseNet121 for feature reuse through dense connections, VGG-19 for robust low-level feature extraction, and EfficientNet-B0 for efficient depth/width/resolution scaling. Ensembling these four maximizes stability and precision across all 7 lesion classes.

LLM Diagnostic Feedback

Classification outputs are passed to a GPT-4 prompt engine, which generates natural-language feedback explaining the characteristics of the detected lesion and recommending next steps. The full pipeline is deployed through a Gradio web interface for real-time image uploads and immediate diagnosis.

Future Work

  • Knowledge graph integration (Neo4j) to ground LLM feedback in medical ontologies
  • Mobile/edge deployment to improve accessibility in remote areas
  • Multi-modal integration of patient history and metadata (age, lesion location) to improve diagnostic precision
