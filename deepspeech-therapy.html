DeepSpeech Therapy

Real-time speech assessment and feedback with a hierarchical deep learning pipeline

PyTorch Autoencoders Transformers GPT-4 Gradio
GitHub →

Overview

DeepSpeech Therapy is a hierarchical deep learning system for real-time speech therapy. It evaluates spoken input to detect speech defects using autoencoders and transformer-based models, then provides personalized corrective feedback through an LLM integration — all accessible through an interactive Gradio interface for anytime practice.

Approach

Speech Clarity Detection

A 1D convolutional autoencoder is trained on the LibriSpeech (train-clean-100) dataset to reconstruct MFCC features from clear speech. At inference, speech is flagged as faulty if its reconstruction error exceeds a dynamic threshold (0.0279), set at the 95th percentile of training errors. This approach reached 96.89% validation accuracy.

Stuttering Diagnosis

Using the SEP-28k dataset (~32,000 audio clips), three architectures were explored for multiclass stutter detection (Block, Prolongation, Repetition, and more): a CNN with attention to capture long-range temporal dependencies in spectrograms, a Conv1D autoencoder combined with a Transformer for sequence modeling over latent embeddings, and a ResNet18 for transfer-learning-based feature extraction. The Transformer-based architecture showed the strongest performance at identifying disfluent segments with high recall.

LLM-Based Virtual Coach

Detected speech errors are passed to GPT-4, which interprets the context of each error and generates natural-language, context-aware suggestions for improving articulation and fluency. The full pipeline — recording, diagnosis, and feedback — is deployed through a Gradio dashboard.

Results

Speech Clarity Detection 96.89% Accuracy
Faulty Articulation Diagnosis 96.0% Accuracy
Stuttering Diagnosis 0.67 – 0.70 F1-score

Future Work

  • Extending the pipeline to clinical disorders such as Dysarthria, Apraxia, and Dementia
  • Domain-specific fine-tuning with state-of-the-art models like Wav2Vec2
  • Gamification with a points-based reward system for fluency and clarity milestones
